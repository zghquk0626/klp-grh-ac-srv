# Panduan Menulis

Tulis isi Bahasa Indonesia di sini memakai Markdown sederhana.

## Sub-judul (dua pagar)

Paragraf biasa. **Tebal** dengan dua bintang, *miring* dengan satu
bintang, `kode` dengan backtick, dan [tautan](https://revolushine.id).

- Poin list dengan strip
- Poin kedua

1. List bernomor dengan angka
2. Poin kedua

> Kutipan dengan tanda lebih-dari di awal baris.

# Writing Guide

Write the English version here using the same simple Markdown.

## Sub-heading (two hashes)

Regular paragraph. **Bold** with double asterisks, *italic* with
single asterisks, `code` with backticks, and [links](https://revolushine.id).

- Bullet list with dashes
- Second point

1. Numbered list
2. Second point

> Blockquote with a greater-than sign at the start of the line.
